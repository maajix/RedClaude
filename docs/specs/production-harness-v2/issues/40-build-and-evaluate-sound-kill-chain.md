**Blocked by:** 39 — Stamp a demonstrated pivot.

**Status:** ready-for-agent

- [ ] Agents may propose member order and capability flow but cannot write canonical chain edges or verdicts.
- [ ] Runtime construction derives edges from compatible `requires` and `provides` values backed by current pivot stamps.
- [ ] Integrity rejects cycles, disconnected members, vocabulary mismatch, cross-Program rows, unsatisfied requirements and ambiguous Identity flow.
- [ ] Reportable reads recheck member validation, Test runs, Artifacts, Receipts, grants, scope, invalidations and review gates.
- [ ] Invalidating any member or pivot makes the chain explicitly unsound and unrenderable without deleting its history.
